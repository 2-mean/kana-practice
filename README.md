# 가나 연습장

히라가나·가타카나를 펜으로 직접 써 보며 연습하는 웹 
**https://2-mean.github.io/kana-practice/**

- 읽기 테스트(글자 → 발음 입력), 쓰기 테스트(발음 → 펜으로 쓰기), 히라가나·가타카나·혼합
- 획순·방향·획수까지 채점: 모양은 맞고 획순이 틀리면 △, 닮은 글자(シ/ツ, ぬ/め, ね/れ/わ …)는 판별 포인트로 구별
- 글자표(누르면 획순 애니메이션), 테스트 중 컨닝, 무한 모드
- 내 단어장: 단어·문장 추가, 한국어 뜻 보고 원고지 칸에 쓰기(히라가나·한자), 한자 읽기와 뜻 맞히기, 기본 단어 172개 불러오기
